# 朱元璋的一生 · 像素史诗

一款可以直接在浏览器中游玩的复古像素风 H5 剧情游戏。

从濠州钟离的放牛娃，到应天奉天殿的开国皇帝。你会经历饥荒、出家、投军、娶妻、鄱阳湖决战与洪武登基，在两场即时战阵中亲自走位、率军破敌。

![标题画面](preview.png)

## 开始游玩

### 在线游玩（GitHub Pages）

直接打开下面的链接即可游玩，无需下载、无需安装：

**https://he-1023.github.io/zhu-yuanzhang-game/**

### 本地游玩

**最简单的方式：双击 `朱元璋的一生.html`。**

这是一个完全独立的单文件版本，HTML、CSS、JavaScript 与全部像素美术、程序化音效都已内嵌，不需要安装依赖，也不需要联网。

也可以打开 `index.html`（需要与 `style.css`、`art.js`、`audio.js`、`game.js`、`battle.js` 放在同一目录）。

推荐使用 Chrome / Edge / Safari 等现代浏览器，横屏或全屏体验更佳。

## 操作

| 按键 | 作用 |
| --- | --- |
| `↑ ↓ ← →` / `W A S D` | 行走、选择菜单 |
| `空格` / `Enter` / `Z` | 交谈、调查、推进对话、确认 |
| `空格`（战斗中） | 释放主帅绝技：战吼 / 火攻 |
| `Esc` | 打开操作说明 |
| 右上角「音」 | 开关程序化音乐与音效 |

触屏设备会显示虚拟方向键与 A 键；手机竖屏时会提示旋转至横屏。

## 内容

- **五个章节**：钟离孤庄 → 皇觉寺 → 投军 → 鄱阳烽火 → 洪武元年
- **两场即时战阵**：夜袭元营、鄱阳湖决战
- **点将出征**：每场战斗前从三条计策中选择，改变战场增益与结局属性
- **选择与属性**：`民心`、`威望` 会随抉择变化，并影响最终结局称号
- **章节存档**：每章开始时自动存档，可从标题界面「续写旧梦」继续
- **像素演出**：开场日落、章节卡、过场字幕、胜利/兵败画面与片尾时间线
- **程序化音频**：WebAudio 合成的五声音阶旋律、战鼓与音效，无外部音频文件

## 小提示

- 先和村民说话，任务栏会告诉你该做什么。
- 战斗里方向键走位，靠近敌人会自动挥刀；空格释放绝技。
- 打不过可以「整军再战」，也可以换一条出征计策。
- 游戏有两处选择会明显改变民心/威望，不必追求唯一答案。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架、无构建步骤、无外部素材。
- 游戏世界使用 640×360 的低分辨率 Canvas 绘制，再以像素化方式放大到 1280×720 舞台。
- 所有场景、人物、头像、战船与特效均由 Canvas 色块现场绘制。
- 音效与背景音乐由 WebAudio 实时合成。
- 存档使用 `localStorage`，键名为 `zhu_life_save_v1`。
- 站点由 GitHub Actions 自动部署到 GitHub Pages，全部资源走相对路径，可在项目子路径下直接运行。
